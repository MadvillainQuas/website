02

Install it

Written for a Samsung. On other Android phones the steps are the same, and the settings may have slightly different names.

  1. Download

    Tap Download for Android above. If your browser warns that this type of file can harm your device, choose Download anyway. When it has finished, tap Open.

  2. Allow “Install unknown apps”

    The first time, Android stops and asks. Tap Settings, turn on Allow from this source for your browser, then go back.

    If the phone says Auto Blocker stopped the install, open Settings › Security and privacy › Auto Blocker, turn it off, install the app, then turn Auto Blocker back on.

  3. Install

    Tap Install. If Play Protect asks to scan the app, choose Scan app, then Install.

  4. Open the app and allow notifications

    Open EPINOIΛ from its new icon. A screen explains game alerts: tap Continue, then choose Allow when Android asks about notifications.

  5. Keep Chrome enabled

    The app runs on Chrome, even when Samsung Internet is your usual browser. If Settings › Apps › Chrome shows an Enable button, tap it, and keep Chrome up to date in the Play Store.

  6. Turn off the old web app's notifications

    If you added EPINOIΛ to your home screen from Samsung Internet before, open that old icon, go to your Profile page and turn notifications off, then remove the old icon. Otherwise every alert arrives twice.

03

Updates

Website changes
Reach the app the next time you open it. There is nothing to download, because the app shows the live website.
A new app
Rarely needed. When it is, Epinoia tells you inside the app. Download it from this page: it installs over the old one and keeps you signed in.
Where the file comes from
Epinoia itself: every release is built from the website's own code and signed with Epinoia's key. Android only installs an update signed with the same key.
04

On an iPhone

There is no iPhone app, and the download above will not open on one. Add EPINOIΛ to your Home Screen instead: it opens full screen, like an app.

  1. Open Epinoia in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Open EPINOIΛ from the new icon and turn notifications on from your Profile page. Game alerts need iOS 16.4 or later.
